# AI 助手与 QQ 机器人使用说明

官网 AI 助手沿用当前登录会话，在输入框旁的「工具」选择有权限的插件模块后提问。管理员在「系统工具」中统一启停插件工具模块。插件自己的模型调用均经宿主 AI/Agent 能力，模型与提供方在宿主配置，不需要每个插件重复登录或填写供应商密钥。

本次检查了 58 个后端业务插件。原先主动注册 AI 工具的插件为 ai-chatbot、mcpanel、minecraft-server、project-progress、questionbank、wallet；本次补充 qqrobot 的「我的游戏账号」和 registration-review 的「我的注册审核」。这些注册工具可被官网助手按当前用户权限选择。其他插件尚未全部提供 AI 工具，不能把目录接通描述为所有业务都已能被 AI 操作。

AI 生成消费方 ai-chatbot、ai-office、mc-news、qqbot-automation、questionbank、web-card 复用宿主 AI SPI。它们的外部公开资料检索与模型账号配置是两回事。

玩家在 QQ 群里 @机器人后发送问题，例如：

- 「我的注册审核通过了吗？」
- 「我绑定了哪些游戏账号？」
- 「最新 Java 快照更新了什么？用中文总结并给官方来源。」
- 「这个版本的漏斗怎么合成？」
- 「在官网 Wiki 找入服教程。」
- 「比较这两款 CPU 在游戏和多线程负载下的表现，注明评测条件。」

群内提问受各群 AI 策略、冷却、额度、静默时间与权限控制。未绑定站点账号时按现有绑定引导处理。官网已登录用户查询本人信息不另要求 QQ 登录。硬件、MC 更新、原版玩法、官网公开 Wiki、健康角色扮演和其他服务器公开信息均可讨论；政治敏感、18+及越权隐私按既定策略拒绝。没有可用检索来源时应明确无法核实。

本服已知配置为 AMD 线程撕裂者 9995WX，企业 U.2 磁盘 16T+2T+2T。磁盘容量不能当成线程数，也不能据此编造内存、跑分、TPS 或阵列可用容量。

官网审核群在「QQ 群自动化」新建该群策略，打开「入群验证」与「以官网审核为准」。最终 approved=true 才自动同意；问卷 passed=true 但仍待人工确认时不自动放行；身份未关联、提供方关闭或接口故障时保留群主人工处理，不允许答案规则或 AI 绕过官网审核。

QQ OAuth OpenID 与官方群成员 OpenID 应按应用与消息作用域核对。已绑定消息身份直接查询宿主账号；相同应用作用域的 OAuth OpenID 可直接关联官网登录账号。不按昵称、玩家自报 ID 或跨应用同值字符串推断身份。

群组管理支持「账号服务群」和「审核迎新群」预设，可分别控制绑定、查询、密码入口、群名片与欢迎消息。欢迎模板可用 #mention 提及新人，#name 表示事件中的成员身份，#group 表示配置的群名。密码入口引导用户在官网验证后重置，不在群聊收集明文密码。

背包、末影箱、潜影盒可用默认触发词查询。多游戏账号先回复账号序号；多潜影盒再回复盒子序号。选择按连接、群与成员隔离，2 分钟过期，可回复「取消」或取消序号。主背包只显示盒子编号，单独打开后渲染盒内 27 格。渲染只读取快照，不改动物品。

B站分享只获取公开封面、标题、简介和原视频链接，已移除播放地址与视频下载路径。
